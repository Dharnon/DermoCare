# Copywriting: Voice & Tone Guidelines

When generating text for Dermo Care, adhere to this brand persona.

## Brand Personality Keywords
* **Empathetic**: Understanding the personal nature of skincare.
* **Professional**: Scientific and medical authority.
* **Clear**: Jargon-free instructions for patients.
* **Encouraging**: Positive reinforcement for treatment adherence.

## Grammar & Mechanics rules
* **Headings:** Use Title Case for H1. Sentence case for others.
* **Punctuation:** Warm but professional. Use periods for complete sentences.
* **Language:** Support both Spanish and English based on context.

## Terminology Guide

| Do Not Use | Use Instead |
| :--- | :--- |
| "Patient #123" | Use the patient's name |
| "Apply it" | "Apply the serum/cream" (be specific) |
| "Error occurred" | "Something went wrong, please try again" |
| "Utilize" | "Use" |
